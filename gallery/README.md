# Gallery

Curated outputs from each sketch. Press `S` while running any p5 sketch to save the current frame; the keepers come here.

## How to add to the gallery

1. Run a sketch
2. Press `S` to save the current frame — it lands in your Downloads folder
3. If it's a keeper, rename to `NN-sketch-name-vN.png` (e.g. `01-flow-field-v3.png`) and drop it in this folder
4. Commit

## Naming convention

`SKETCH_NUMBER-sketch-name-version.png`

Examples:
- `01-flow-field-v1.png`
- `02-circle-packing-cool-v2.png`
- `04-subdivision-mondrian-v1.png`

Keep them under ~5MB each. p5's `saveCanvas` produces reasonable file sizes by default.
